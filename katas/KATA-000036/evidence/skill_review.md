# OBS-022 — Complete lexicographic ranking keys

A result category is insufficient for ordering complex results: the key must include every specified tiebreaker in precedence order. Handle wheel A-2-3-4-5 separately, and preserve tied winners in input order. Random generators must produce valid domain instances (distinct cards per hand), or the oracle can fail for fixture errors rather than implementation defects. This example is not measured proof of improved Ninja transfer.
