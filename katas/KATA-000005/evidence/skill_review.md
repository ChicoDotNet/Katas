# OBS-006: Rover command/obstacle contract
Status: bounded observation, local tests GREEN; not an established general principle.
An incremental API can reject malformed command sequences **before any mutation** while still permitting intentional partial progress on environmental obstacles. Treat these failure classes differently. The word "spherical" is ambiguous for a discretized map: choose torus explicitly and test wraparound rather than silently guessing. The RED stub initially failed to compile because tagged Go files also carried shared types; moving domain declarations to an untagged module created meaningful behavioral RED. This lesson applies to build variants as well as to API contracts, but evidence from one Go kata does not establish generalizability. Other candidate geometric mappings remain unimplemented.
