# OBS-007: category alert threshold and calendar boundaries

Status: one reproducible Ruby observation; local RED, GREEN and Python differential oracle pass, remote CI not yet assessed.

**Exact inequality:** when specifications state a fixed relative increase, represent amounts in the natural integer minor unit and compare integer cross-products; do not introduce floating-point percentages without a need. Explicitly distinguish a missing baseline from a baseline of zero and set a policy for positive-new and zero/zero amounts.

**Outside-in service:** source and sender are injected so failures in IO or calendar rollover need not be represented by live API calls in every test. This extends OBS-002 from PHP but does not prove improvement in transfer on new unseen cases.

**Limits:** recognized categories, simplified payment source and no refunds/chargebacks, currency conversion, external communication retries, financial compliance or transactional outbox; real products require those policies. No speed claim.
