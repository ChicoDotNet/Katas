# OBS-011: event streams with look-ahead bonuses
Scoring one completed bowling game requires a bounded stream of pin events with frame boundaries. A strike consumes one roll in ordinary frames but references the next *two* rolls; a spare consumes two and references one. The tenth frame is exceptional because bonus balls are within the same frame. Separate input validity, frame parsing and scoring semantics; test perfect game, all spares, ordinary open frames and incomplete sequences. A Python frame model provides a distinctly structured oracle against C index arithmetic. The data supports correctness within this contract, not improved Ninja success or speed elsewhere.
